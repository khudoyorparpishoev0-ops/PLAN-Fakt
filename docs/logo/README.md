# Логотип IT-HONA

- `it-hona-logo-original.svg` — исходник заказчика как получен (CorelDRAW,
  04.08.2026). Надпись «it-hona» здесь лежит текстом со встроенным
  SVG-шрифтом Uni Neue Light — **браузеры такие шрифты не поддерживают**,
  напрямую в веб этот файл ставить нельзя (надпись отрисуется системным
  шрифтом).
- `it-hona-logo.svg` — рабочая версия: глифы надписи переведены в контуры
  программно, по метрикам из самого исходника (advance-ширины, кегль 48.19,
  растяжение 1.55277, двойная печать текста — фирменное утолщение).
  Цвет — `currentColor`. Именно эти контуры зашиты в компонент
  `Logo` (`src/components/ui.tsx`).

В интерфейсе по умолчанию показывается только знак: рядом во всех местах
уже стоит текст «IT-HONA», а надпись высотой 7px превращалась бы в кашу.
Полная версия — `<Logo full />`.
