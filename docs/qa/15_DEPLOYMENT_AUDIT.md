## Внесённые изменения в развёртывание

- `deploy/nginx-frontend.conf`: заголовки безопасности и CSP для статики.
- `deploy.sh`: `server_tokens off` и три заголовка в системном nginx.

Обе правки идемпотентны: `deploy.sh` перезаписывает конфиг nginx целиком при
каждом запуске, поэтому заголовки появятся при ближайшем развёртывании.

## Порядок обновления боевого сервера

```bash
sudo sh /opt/app/app/deploy.sh
sh /opt/app/app/deploy/check-service.sh        # 15 проверок
docker compose exec backend npm run check:audit
```

После обновления в браузере — Ctrl+Shift+R.
