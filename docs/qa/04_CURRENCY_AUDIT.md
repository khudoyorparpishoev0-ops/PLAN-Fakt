# Аудит валют

Справочник — 156 действующих кодов ISO 4217; названия и точность берутся из
ICU, а не выписаны руками. Валюта учёта одна — сомони.

| Проверка | Результат |
| --- | --- |
| Справочник отдаёт все валюты мира | 156 |
| Иена без копеек (`digits` 0) | ok |
| Кувейтский динар с тремя знаками (`digits` 3) | ok |
| Названия по-русски («Доллар США») | ok |
| Бухгалтеру справочник доступен | 200 (иначе нечего выбрать в заявке) |
| Выдуманный код `XYZ` | 422 |
| Операция в валюте без курса | 422 `no_exchange_rate` |
| 100 USD по курсу 10,50 | 1050 TJS |
| Курс, вписанный в форму, важнее справочника | ok (100 × 20 = 2000) |
| Заявка в валюте: сумма в сомони отдельным полем | `amountTjs` ok |
| Заявка без курса | принимается, `amountTjs = null`, в итоги не входит |
| Расход в валюте попал в план-факт в сомони | ok |

## Исторический курс

Ключевая проверка задания: курс не должен переписываться задним числом.

1. Задан курс EUR на 01.08 — 10,5. Операция 01.08 на 100 EUR → **1050 TJS**.
2. Добавлен курс EUR на 05.08 — 10,6.
3. Карточка операции 01.08: сумма **1050**, `rate` 10.5, `rateDate` 2026-08-01.
4. Новая операция 06.08 на 100 EUR → **1060 TJS**.

Курс фиксируется в самой операции, поэтому прошлые отчёты не меняются.

## Точность

Шкала хранения фиксированная — дирамы (×100). У валют с нулём знаков сумма
округляется до целого. У шести валют с **тремя** знаками (KWD, BHD, OMR, JOD,
LYD, TND) третий знак округляется до сотых — ограничение записано в
`docs/DEPLOY.md`; для расчётов компании это доли тийина.
