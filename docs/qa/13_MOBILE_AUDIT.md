# Аудит мобильной версии

Проверены четыре ширины на кабинете бухгалтера — том экране, который реально
открывают с телефона.

| Ширина | Горизонтальная прокрутка |
| --- | --- |
| 360 px | нет (перелив 0 px) |
| 375 px | нет |
| 390 px | нет |
| 430 px | нет |

Снимки экранов сохранены в ходе прогона.

## Что проверено дополнительно

- На телефоне обе десктопные формы заменяет единая форма заявки: крупное поле
  суммы, валюта единицей измерения рядом с ним.
- Подпись кнопки называет недостающее поле («Укажите сумму», «Выберите
  проект»), а не остаётся серой без объяснения.
- Кнопки выбора не мельче 44 px — проверено на переключателе срочности и на
  селекте валюты (44 px).
- Сайдбар на телефоне — выдвижное меню; свёрнутое не ловит нажатия и не
  попадает в скринридер (`visibility: hidden`).

Замечаний нет.
