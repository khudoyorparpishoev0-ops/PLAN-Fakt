# Аудит журнала операций

| Проверка | Результат |
| --- | --- |
| Пагинация отдаёт страницу и общее число | ok (`total` 75) |
| Фильтр по типу | ok, в выдаче только запрошенный тип |
| Комбинация «тип + период» сужает выборку | 48 ≤ 61 |
| Запредельный `offset=100000` | пустая страница, `total` прежний, не 500 |
| Поиск по кириллице | находит |
| Поиск не зависит от регистра | «оплат» и «ОПЛАТ» дают одинаковые 4 |
| Несуществующий id | 404 без стека и строки подключения |
| Нечисловой id | 400, не 500 |
| Пустая выборка | «Под фильтры ничего не подошло» + кнопка сброса |

Фильтры серверные: тип, период, счёт, контрагент, статья, проект, диапазон
суммы, подтверждённость, поиск, исключение архивных. Комбинируются.

Валюта операции видна в строке журнала второй строкой («1 000 USD» под суммой
в сомони) — журнал считается в сомони, но валютную операцию видно без
открытия карточки.
