# Аудит интерфейса

Проверено в браузере (Chromium, Playwright) на живых данных.

| Проверка | Результат |
| --- | --- |
| 12 экранов директора открываются | 12 из 12 |
| Ни на одном экрана нет `NaN`, `undefined`, `[object Object]`, `Infinity` | ok |
| Экраны администратора («Пользователи», «Настройки») | открываются |
| Разметка в данных не выполняется | ok, `<img src=x onerror=...>` показан текстом |
| Три нажатия «Отправить» подряд | один запрос |
| Пустая выборка объясняется словами | «Под фильтры ничего не подошло» + кнопка сброса |
| Ошибка сервера: стек пользователю | не показывается |
| Ошибка сервера: сообщение видно | видно |

## Состояния экранов

В `src/components/states.tsx` есть три состояния — загрузка (скелет таблицы),
пустое и ошибка. Пустое состояние различает «данных нет вовсе» и «под фильтры
ничего не подошло» и предлагает действие, а не констатирует пустоту.

## Единственное замечание

На каждом экране в консоли — неудачный запрос к `fonts.googleapis.com`
(`ERR_CONNECTION_RESET`). Интерфейс при этом работает, но рисуется системным
шрифтом. Описано как UI-001.

Других ошибок консоли, необработанных обещаний и предупреждений React о ключах
или неуправляемых полях не зафиксировано.
