# Handoff: IT-HONA — модуль «Финансы: План-Факт» + кабинет бухгалтера

## Overview
Финансовый модуль для IT-HONA LLC (Таджикистан, валюта TJS): учёт доходов/расходов по проектам «план–факт», журнал операций, справочники, а также отдельный личный кабинет операционного бухгалтера с заявками на оплату/машину и согласованием директором.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (прототипы внешнего вида и поведения), а НЕ production-код. Задача: **воссоздать эти экраны в целевом стеке** (React/Vue/и т.п.) с использованием паттернов существующей кодовой базы; если кодовой базы нет — выбрать подходящий фреймворк (рекомендация: React + любой UI-слой без тяжёлых библиотек, стили можно перенести 1:1).

`.dc.html` файлы открываются в браузере напрямую (рядом должен лежать `support.js`; для ТЗ — `doc-page.js`). Логика прототипа — класс `Component` внутри `<script>` в конце каждого файла; данные-примеры лежат там же (массивы `PROJECTS`, `OPS`, `ART`, `PAY`, `CAR` и т.д.) — используйте их как fixture-данные.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы, статус-бейджи и состояния — финальные, воспроизводить пиксельно. Тексты и цифры — реалистичные примеры.

## Требования (спека)
Полное ТЗ — `ТЗ Финансы IT-HONA.dc.html` (11 разделов): роли и права, поэкранные требования, статусные модели и переходы, модель данных (User, Project, Article, Operation, Request, Plan), бизнес-правила (пороги отклонений: 0% «По плану», ≤5% «В норме», 5–20% «Экономия», >20% «Проверить план»; одобренная заявка порождает плановую операцию), эскиз REST API, NFR, критерии приёмки. **Читать в первую очередь.**

## Screens / Views

### Финансы План-Факт.dc.html — админ-панель (роль: администратор/руководитель)
Каркас: тёмно-зелёный сайдбар 238px (#123A26) + белая шапка 60px + контент на фоне #EEF1EE, отступ контента 22–28px.
- **План-Факт (дашборд)** — сегмент-контрол периодов (День…Год), фильтры, 4 KPI-карточки (25px цифры IBM Plex Sans, tabular-nums), таблица статей план/факт/откл./% со статус-бейджами.
- **Операции** — сворачиваемая панель фильтров слева 236px (чекбоксы типов, дата оплаты, мультиселекты, сумма от–до); таблица: чекбокс, Дата ▾, Счёт, Тип (← #22935B приход / → #C86B5E расход), Контрагент, Статья + тег [Доходы]/[Расходы] + серое примечание, Проект, Сумма (+зелёная/−красная, «,00 TJS»); группировка «Сегодня…/Вчера и ранее».
- **Проекты** — список/группы, статусы Плановый/В работе/Завершён, архив, итоговая строка, действия в строке (карточка, архив, правка, удаление), экспорт Excel.
- **Справочники** — подменю слева (Контрагенты, Учётные статьи, Мои счета, Мои юрлица / Товары, Услуги); Учётные статьи: вкладки Доходы/Расходы/Активы/Обязательства/Капитал, дерево с «+», замок у системных.
- **Настройки/Пользователи** — учётные записи, права.
- Мобильная версия — переключатель «Компьютер/Телефон» в шапке.

### Кабинет Бухгалтера.dc.html — кабинет операционного бухгалтера
Тот же каркас; меню: ЗАЯВКИ (Заявки на оплату, Заявки на машину), ОТЧЁТЫ (Список всего/История, Проекты); внизу профиль пользователя.
- **Заявки на оплату** — форма (Проект, Сумма+валюта, Наименование, документ) → «Отправить на утверждение Директору»; таблица «Мои последние заявки» с двумя статус-бейджами (свой + Директор).
- **Заявки на машину** — вкладки «Заявка на поездку» (Проект, Цель, Км + фото одометра, Контрагент) и «Расходы на авто» (Категория: Бензин/Ремонт/Мойка/Штраф/Запчасти, Сумма, чек).
- **Список всего / История** — 4 карточки-фильтра, пончик «Расходы по категориям», линия по месяцам, реестр с вкладками Оплаты/Поездки/Авто, действия 👁 📷 📄 🗑.
- **Проекты** — только свои заявки: счётчик, «Одобрено», «Ждёт решения», статус.
- KPI-ряд: Отправлено / На рассмотрении / Одобрено / Отклонено.

## Interactions & Behavior
- Переключение разделов/вкладок/периодов — мгновенно, без перезагрузки; активный пункт меню — заливка акцентом, hover пунктов rgba(255,255,255,.06–.07).
- Строки таблиц: hover #F8F7F4; клик — карточка/детализация.
- Фильтры комбинируются по «И»; панель фильтров сворачивается (состояние запоминается).
- Валидация форм: суммы > 0, наименование 3–200 симв., фото одометра обязательно, чек обязателен при ≥100 TJS; кнопка отправки активна при валидной форме; после отправки — тост + строка в списке со статусом «Отправлено».
- Статусы заявки: Черновик → Отправлено → На рассмотрении → Одобрено/Отклонено (правка автором — только Черновик/Отклонено; удаление — только Черновик).

- Статусы: зелёный #1A7A4B/#E4F3E9/#22935B; жёлтый #9A6B00/#FCF1D6/#E5A400; красный #B93227/#FAE7E4/#D24A3D; синий #3E6B8A/#E7F0F6/#4E86AE; серый #6B7370/#EFEEEA/#A6ACA8 (текст/фон/точка бейджа).
- Шрифты: Golos Text (400–800) — интерфейс; IBM Plex Sans (400–700) — цифры/даты/ID, `font-variant-numeric: tabular-nums`.
- Размеры: базовый текст 13–13.5px, заголовки таблиц 10.5px uppercase ls .05em, KPI 25px/700, заголовок экрана 16px/700; радиусы: карточки 12–14px, кнопки 9–11px, бейджи 99px; кнопка-акцент: фон акцент, белый текст, hover `brightness(.94)`.
- Формат сумм: пробел-разделитель тысяч, знак +/− цветом, код валюты TJS 10.5–12px.
